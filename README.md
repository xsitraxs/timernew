# Таймер — настольное приложение для Windows 10/11 (C# + WinUI 3)

Полноценное запускаемое приложение Windows (MSIX), а не сайт и не WebView.
Интерфейс — в стиле Windows 11: Mica-фон, тёмная тема по умолчанию, скруглённые
карточки, крупные цифры, плавный круговой индикатор и один акцентный цвет
`#4CC2FF`. Весь интерфейс — на русском языке.

![Иконка приложения](TimerApp/Assets/Square150x150Logo.png)

## 🟢 Обычному пользователю (без Visual Studio)

**Ничего собирать не нужно.** Готовое приложение собирается автоматически
на GitHub — просто установите его как обычную программу:

1. Скачайте **один файл `TimerSetup.exe`** из раздела **Releases**
   (последняя версия). Внутрь него уже встроены приложение, среда выполнения
   и сертификат.
2. Дважды щёлкните **`TimerSetup.exe`** → разрешите права администратора (UAC).
3. Откройте «Пуск» → введите **Таймер**.

Подробная инструкция и решение типичных проблем: [INSTALL.md](INSTALL.md).
Раздел ниже — только для разработчиков, которые хотят собрать проект сами.

## Возможности

- **Установка времени** — часы (0–23), минуты и секунды (0–59), поля `NumberBox`
  со спиннерами.
- **Управление** — «Старт», «Пауза», «Продолжить», «Сброс» и «+1 мин» во время
  отсчёта и паузы. Кнопки меняются в зависимости от состояния.
- **Понятные состояния** — «Таймер не запущен», «Идёт отсчёт», «Пауза»,
  «Время вышло»: подпись и цветная точка под кольцом, панель InfoBar на финише,
  мигание крупных цифр.
- **Круговой индикатор** — кольцо плавно убывает (обновление каждые 50 мс),
  внутри — крупные цифры `MM:SS` или `H:MM:SS`.
- **Пресеты** — 1, 5, 15, 25 и 45 минут + свои пресеты: кнопка «Добавить пресет»
  (название, минуты, секунды), применение щелчком по карточке, удаление —
  кнопкой с корзиной. Свои пресеты сохраняются между запусками.
- **Точный отсчёт** — при старте фиксируется фактическое время окончания
  (`DateTimeOffset.UtcNow + длительность`), а интерфейс лишь пересчитывает
  остаток. Задержки перерисовки и сворачивание окна ошибку не накапливают.
- **Работа в свёрнутом окне** — по окончании: звуковой сигнал, системное
  уведомление Windows, окно разворачивается, цифры мигают. Клик по уведомлению
  активирует окно.
- **Звук** — четыре встроенные мелодии на выбор (классическая, колокольчики,
  цифровые бипы, мягкая) или **свой звуковой файл** (wav/mp3/m4a/flac копируется
  в данные приложения). Сигнал звучит около 35 секунд или до вашего действия;
  есть слайдер громкости, кнопка отключения звука и кнопка «Проверка».
- **Темы** — тёмная (по умолчанию) и светлая, переключатель в заголовке окна.
- **Время на панели задач** — пока идёт отсчёт, в заголовке окна и на его
  кнопке в панели задач виден живой остаток («12:34 — Таймер»), виден и в Alt-Tab.
- **Мини-окно поверх всех окон** — кнопка в заголовке превращает окно
  в маленькое (400×460), всегда поверх остальных: только кольцо, цифры,
  статус и кнопки управления. Повторное нажатие возвращает как было.
  При узком окне автоматически включается компактная раскладка
  (кольцо 208 px, цифры 40 pt).
- **Таймер переживает перезапуск** — идущий или приостановленный отсчёт
  сохраняется: после закрытия приложения, его падения или перезагрузки ПК
  таймер сам продолжится с честным остатком при следующем запуске.
  Если время вышло, пока вас не было, приложение покажет «Время вышло»
  без внезапного звукового сигнала.
- **Сохранение настроек** — тема, громкость, mute, последняя длительность и свои
  пресеты переживают перезапуск.
- **Горячие клавиши**:
  - `Пробел` — старт / пауза / продолжить;
  - `Enter` — старт;
  - `Esc` — сброс.
  (В полях ввода и на сфокусированной кнопке пробел работает как обычно.)

## Технологии и пакеты NuGet

| Пакет | Версия | Зачем |
|---|---|---|
| `Microsoft.WindowsAppSDK` | 1.6.240923002 | WinUI 3, Mica, AppNotifications, AppWindow |
| `Microsoft.Windows.SDK.BuildTools` | 10.0.26100.1742 | Сборка MSIX |
| `CommunityToolkit.Mvvm` | 8.2.2 | `ObservableObject`, `RelayCommand` |

- Target framework: `net8.0-windows10.0.19041.0`, минимум Windows 10 1809
  (17763); полноценно раскрывается на Windows 11.
- Приложение **упакованное (single-project MSIX)**: пакетная идентичность нужна
  для тост-уведомлений `AppNotificationManager` и хранилища
  `ApplicationData.LocalSettings`. Для unpackaged-варианта уведомлениям
  потребовался бы COM-активатор в манифесте — здесь он не нужен.

## Пошаговая сборка и запуск в Visual Studio

### 1. Требования

1. Windows 10 (1809+) или Windows 11; для разработки рекомендуется Windows 11.
2. **Visual Studio 2022 (17.8+)**. При установке в Visual Studio Installer
   отметьте рабочую нагрузку **«Разработка приложений для Windows»**
   (Windows App SDK / WinUI) и компонент **.NET 8 SDK**. Отдельно .NET 8 SDK
   можно поставить с сайта Microsoft.
3. Включите **режим разработчика**: Параметры → Конфиденциальность и защита →
   Для разработчиков → Режим разработчика = Вкл. (Нужен для установки
   отладочного MSIX без магазина.)

### 2. Открытие и первый запуск

1. Откройте `TimerApp.sln` в Visual Studio.
2. При первом открытии Visual Studio восстановит пакеты NuGet автоматически. Если восстановление завершилось с ошибками, выполните **Сборка → Восстановить пакеты NuGet** и убедитесь, что репозиторий nuget.org доступен.
3. Выберите конфигурацию **Debug** и платформу **x64** (или ARM64 на ARM-устройстве)
   на панели инструментов.
4. Стартовый проект — **TimerApp**; профиль запуска — **TimerApp (Package)**.
5. Нажмите **F5** (или зелёную кнопку запуска). Visual Studio соберёт MSIX,
   развернёт пакет в системе и запустит приложение. Откроется окно «Таймер»
   в тёмной теме с пресетом 5 минут.

### 3. Сертификат подписи (если VS попросит)

Пакет подписывается тестовым сертификатом. Если при первом запуске появится
ошибка подписи/сертификата:

1. Откройте `Package.appxmanifest` двойным щелчком.
2. Вкладка **«Упаковка»** → **«Выбрать сертификат…»** → **«Создать…»** →
   OK (пароль можно оставить пустым).
3. Снова нажмите F5.

### 4. Проверка функций

1. Нажмите пресет «1 мин», затем «Старт». Сверните окно и дождитесь конца
   минуты: прозвучит сигнал (около 35 секунд), придёт уведомление Windows, окно
   развернётся, цифры замигают.
2. Проверьте паузу пробелом: остановите отсчёт, подождите — после
   «Продолжить» таймер не должен «нагнать» время паузы (остаток считается
   от нового дедлайна при возобновлении).
3. Добавьте свой пресет, закройте приложение и запустите снова (F5 или из меню
   «Пуск» — приложение установлено как «Таймер») — пресет, тема, громкость и
   последняя длительность должны сохраниться.

### 5. Публикация готового MSIX (необязательно)

1. Переключите конфигурацию в **Release**, платформа — нужная (x64 / ARM64).
2. Правый щелчок по проекту **TimerApp** → **Опубликовать** →
   **Создать пакеты приложения…** (Create App Packages).
3. Выберите «Только загрузка неопубликованных приложений» (Sideloading),
   укажите сертификат, архитектуры — мастер создаст `.msix` (+ `.cer`).
4. На целевом ПК: установите сертификат `.cer` в «Локальный компьютер →
   Доверенные лица», затем запустите `.msix`. Либо используйте готовые профили
   публикации `Properties/PublishProfiles/win-x64.pubxml`.

## Как это устроено внутри

- **Точность.** `TimerService.Start()` сохраняет `EndTimeUtc = UtcNow + duration`.
  `DispatcherQueueTimer` (50 мс) только пересчитывает `Remaining = EndTimeUtc − UtcNow`
  и перерисовывает кольцо. На паузе остаток фиксируется, при продолжении строится
  новый дедлайн — поэтому ни лаги интерфейса, ни пауза не сдвигают финиш.
- **Уведомления.** `App.Register()` в `App.OnLaunched`, показ —
  `AppNotificationBuilder` в `NotificationService`. Если уведомления запрещены
  политикой или включён «Не беспокоить», приложение не падает: остаются звук,
  разворачивание окна и мигание цифр.
- **Звук.** `MediaPlayer` играет `ms-appx:///Assets/alarm.wav`. Замените этот
  файл своим `.wav` с тем же именем, чтобы поменять сигнал.
- **Настройки.** `ApplicationData.LocalSettings` (тема, громкость, mute,
  последняя длительность, JSON своих пресетов). Если пакетная идентичность
  вдруг недоступна (ручной запуск exe вне MSIX), `SettingsService` пишет
  резервный `%LocalAppData%\TimerApp\settings.json`.
- **Фон Mica.** `MainWindow.SystemBackdrop = new MicaBackdrop()`; на системах
  без поддержки останется обычный фон темы.

## Частые проблемы

- **«Приложение не запускается из VS, ошибка пакета»** — включён ли режим
  разработчика и выбран ли профиль **TimerApp (Package)**, а не запуск exe.
- **Нет уведомлений** — проверьте Параметры → Система → Уведомления: для
  приложения «Таймер» уведомления должны быть разрешены; отключите «Не беспокоить».
- **Нет звука** — проверьте кнопку mute в заголовке/карточке «Звук», слайдер
  громкости и кнопку «Проверка».
- **Ошибки восстановления NuGet** — нужен доступ к nuget.org; версии пакетов
  зафиксированы в `TimerApp.csproj`.
