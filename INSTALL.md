# Установка «Таймера» — для обычных пользователей

**Visual Studio не нужна. Ничего собирать не нужно.**
Приложение уже собрано в готовый установщик Windows (`.msix`).

## Что скачать

Откройте страницу проекта на GitHub и скачайте готовый архив одним из способов:

- **Раздел Releases** (если есть релиз): скачайте все файлы из релиза в одну папку.
- **Или раздел Actions**: откройте последний успешный запуск
  «Собрать установщик для Windows (MSIX)» → внизу страницы блок **Artifacts** →
  `TimerApp-Windows-x64` (нужен вход в GitHub).

В папке должны лежать рядом:

| Файл | Что это |
|---|---|
| `TimerApp_..._x64.msixbundle` (или `.msix`) | само приложение |
| `TimerApp.cer` | сертификат, без него Windows не поставит пакет |
| `Install.bat` | установка в один клик |
| `install.ps1` | служебный скрипт установщика |

## Установка — 3 шага

1. **Распакуйте** архив в обычную папку (например, на рабочий стол).
2. **Дважды щёлкните `Install.bat`.**
   - Windows спросит разрешение администратора — нажмите **«Да»**.
   - Скрипт сам установит сертификат и приложение, затем напишет «Готово!».
3. **Откройте меню «Пуск»** и введите **Таймер** — запускайте как обычную программу.

Всё. Приложение работает как любая программа Windows: есть в «Пуске»,
удаляется через Параметры → Приложения.

## Если не устанавливается

- **«Нужен сертификат / пакет не подписан»** — запускайте именно `Install.bat`,
  а не сам `.msix`: установщик сначала ставит сертификат.
- **Windows блокирует установку приложений не из магазина** — включите один раз:
  **Параметры → Конфиденциальность и защита → Для разработчиков →
  Режим разработчика = Вкл**, затем снова запустите `Install.bat`.
- **SmartScreen ругается** — «Подробнее» → «Выполнить в любом случае».
  Это нормально для приложений, установленных не из Microsoft Store.
- **Старая версия уже стоит** — просто запустите `Install.bat` ещё раз,
  пакет обновится поверх.

## Ручная установка (если Install.bat чем-то не нравится)

1. Дважды щёлкните `TimerApp.cer` → «Установить сертификат» →
   «Локальный компьютер» → «Поместить все сертификаты в следующее хранилище» →
   **Доверенные люди** → Готово.
2. Дважды щёлкните файл `.msixbundle` (или `.msix`) → «Установить».

## Разработчикам

Сборка из исходников в Visual Studio и автоматическая сборка на GitHub Actions
описаны в [README.md](README.md). Готовый MSIX собирает workflow
`.github/workflows/build-msix.yml` на Windows-сервере GitHub:
запуск вручную — Actions → «Собрать установщик для Windows (MSIX)» →
Run workflow; публикация в Releases — по тегу вида `v1.0.0`.
