# Установка «Таймера» — для обычных пользователей

**Visual Studio не нужна. Ничего собирать не нужно.**
Скачивается **один файл** — `TimerSetup.exe`. Внутри него уже лежат само
приложение, среда выполнения, сертификат и сценарий установки.

## Установка — 3 шага

1. Откройте страницу проекта на GitHub → раздел **Releases** → скачайте
   **`TimerSetup.exe`** из последнего релиза (например, v1.0.2).
2. **Дважды щёлкните `TimerSetup.exe`.**
   - Windows спросит разрешение администратора — нажмите **«Да»**.
   - Откроется окно установщика; когда он напишет «Готово!» — нажмите Enter.
3. **Откройте меню «Пуск»** и введите **Таймер** — запускайте как обычную программу.

Всё. Приложение работает как любая программа Windows: есть в «Пуске»,
удаляется через Параметры → Приложения.

## Если что-то мешает

- **Синее окно SmartScreen «Windows защитила ваш компьютер»** —
  нажмите «Подробнее» → «Выполнить в любом случае». Это стандартное
  предупреждение для программ, установленных не из Microsoft Store
  (у установщика нет платного коммерческого сертификата — только бесплатный).
- **Windows блокирует установку приложений не из магазина** — включите один раз:
  **Параметры → Конфиденциальность и защита → Для разработчиков →
  Режим разработчика = Вкл**, затем снова запустите `TimerSetup.exe`.
- **Отменили запрос администратора (UAC)** — просто запустите файл ещё раз
  и нажмите «Да»: без прав нельзя установить сертификат приложения.
- **Старая версия уже стоит** — просто запустите новый `TimerSetup.exe`,
  приложение обновится.

## Для старых релизов (v1.0.x, если скачали именно их)

Там вместо одного EXE лежит несколько файлов: положите их все в одну папку
и запустите `Install.bat` (он сам попросит права администратора).
Начиная с v1.0.2 используйте только `TimerSetup.exe`.

## Разработчикам

Как устроен однофайловый установщик, сборка из исходников в Visual Studio
и автоматическая сборка на GitHub Actions описаны в [README.md](README.md)
и [installer/README.md](installer/README.md). Готовый `TimerSetup.exe`
собирает workflow `.github/workflows/build-msix.yml` на Windows-сервере
GitHub: публикация в Releases — по тегу вида `v1.0.2`.
